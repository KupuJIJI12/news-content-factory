Ты помогаешь настроить автоматический сбор новостей с сайта {{url}}.

Ниже упрощённый скелет HTML-страницы со списком новостей. Каждая строка — элемент в виде тег.класс#id; у ссылок в квадратных скобках адрес, после двоеточия — начало текста элемента. Отступ показывает вложенность.

Найди повторяющийся блок одной новости в списке новостей и верни CSS-селекторы:
- itemSelector — выбирает каждый блок новости на странице (только новости списка, без меню, рекламы и блоков «популярное»);
- linkSelector — внутри блока ссылка на полную новость; текст этой ссылки — заголовок новости;
- titleSelector — внутри блока элемент с заголовком, если заголовок не в тексте ссылки, иначе null;
- dateSelector — внутри блока элемент с датой публикации или null, если даты нет;
- dateFormat — формат даты в стиле .NET (например dd.MM.yyyy HH:mm), если дата записана необычно, иначе null.

Используй только теги и классы, которые есть в скелете. Не придумывай классы. Селекторы должны быть простыми, например div.news-item или ul.list > li.
