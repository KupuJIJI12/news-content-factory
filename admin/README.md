# Админка NewsFactory (React SPA)

React + TypeScript + Vite + Mantine. В разработке Vite проксирует `/api`, `/hubs` и `/hangfire` на бэкенд
(по умолчанию `http://localhost:5080`, переопределяется переменной `VITE_API_TARGET`). В продакшене SPA раздаёт nginx (план 3).

## Локальный запуск

1. Бэкенд (PostgreSQL должен быть запущен):

   ```powershell
   $env:ConnectionStrings__Postgres = "Host=localhost;Database=newsfactory;Username=postgres;Password=<пароль>"
   $env:ADMIN_LOGIN    = "admin"
   $env:ADMIN_PASSWORD = "<пароль админки>"
   $env:MAX_CHANNEL_CHAT_ID = "<id тестового канала>"   # необязательно
   $env:MAX_BOT_TOKEN       = "<токен бота>"             # необязательно
   $env:GIGACHAT_AUTH_KEY   = "<ключ GigaChat>"          # необязательно
   dotnet run --project src/NewsFactory.Api --urls http://localhost:5080
   ```

   Первая учётка создаётся из `ADMIN_LOGIN`/`ADMIN_PASSWORD`, только если пользователей ещё нет.

2. Интерфейс:

   ```powershell
   npm --prefix admin install
   npm --prefix admin run dev
   ```

   Открыть http://localhost:5173.

## Команды

| Команда | Что делает |
|---|---|
| `npm --prefix admin test` | тесты (Vitest + Testing Library) |
| `npm --prefix admin run build` | проверка типов и сборка в `admin/dist` |
| `npm --prefix admin run lint` | только проверка типов |

## Чек-лист ручной приёмки

Выполняется на своём ПК. Бэкенд и интерфейс запущены, как описано выше. `MAX_CHANNEL_CHAT_ID` указывает на **тестовый** канал, токен бота и ключ GigaChat заданы.

- [ ] **Вход и выход.** Неверный пароль даёт ошибку. Верный открывает очередь. «Выйти» возвращает на страницу входа. После выхода `/` снова требует вход.
- [ ] **Живые счётчики.** Откройте очередь и в другой вкладке запустите сбор источника (Hangfire → Recurring jobs → Trigger now). Когда появится новый черновик, «На проверке N» и заголовок вкладки обновятся без перезагрузки (в пределах минуты).
- [ ] **Правка черновика.** Откройте сюжет, измените заголовок и текст, нажмите «Сохранить» — появится «Версия N (правка)». Если обновить страницу, не сохранив правки, появится предложение «Восстановить».
- [ ] **Перегенерация.** «Перегенерировать» с пожеланием «короче» создаёт новую версию. Если есть несохранённые правки, сначала появляется подтверждение.
- [ ] **Превью Max совпадает с постом.** Опубликуйте сейчас и сравните пост в тестовом канале с превью: жирный заголовок, абзацы, хэштеги, подпись к фото.
- [ ] **Публикация по расписанию.** Поставьте время «через 5 минут» по Самаре и нажмите «Запланировать»: сюжет уходит во вкладку «Запланированные», пост выходит в указанное время. «Отменить публикацию» на другом сюжете возвращает его на проверку.
- [ ] **Дневной лимит.** Временно поставьте лимит 1 в «Настройки → Города → Отрадный → Канал Max» и опубликуйте второй пост. Сначала появится предупреждение «Дневной лимит будет превышен», затем окно «Опубликовать всё равно», и пост уйдёт. После проверки верните лимит.
- [ ] **Своё фото.** «Загрузить своё» с подписью «Фото: …» показывает фото в превью. В канале пост выходит с фото и подписью. Если взять фото источника без разрешения, сначала появится подтверждение.
- [ ] **Проверка источника.** «Источники» → otradny.org → «Проверить» показывает список новостей с датами по Самаре и числом фото. Если испортить селектор, проверка даёт понятную ошибку.
- [ ] **Автонастройка источника.** «Источники» → «Добавить», в поле «Сайт для автонастройки» укажите страницу новостей, например `https://vestnikotradnogo.ru/`, и нажмите «Настроить автоматически». Появится способ («Найдена RSS-лента», «Определено по структуре страницы» или «Подобрано LLM») и найденные новости. Для страницы без новостей придёт понятное сообщение и откроется ручная настройка.
- [ ] **Пауза сбора.** Выключите «Сбор новостей» в шапке и подтвердите. Появится бейдж «Сбор на паузе», новые новости перестанут приходить, а «Проверить» у источника продолжит работать. Включите сбор обратно.
- [ ] **Города.** «Настройки → Города» → «Добавить город», например Кинель: укажите ключевые слова и порог. В карточке города задайте ID чата канала и включите публикацию. В форме источника отметьте оба города: у одного включите «Все новости источника — про город», у другого оставьте выключенным. В очереди и источниках появится фильтр по городу.
- [ ] **Настройки.** Ключевые слова и порог сохраняются. В «Промпты» сохраните новую версию, затем сделайте активной старую. Переменная с опечаткой, например `{{citty}}`, даёт ошибку у поля. В «Расход» видны токены за сегодня и за месяц.
- [ ] **Телефон.** SSH-тоннель из Termius/JuiceSSH: локально `localhost:5173`, в проде (план 3) `localhost:8080`. Очередь показывается карточками, у сюжета вкладки «Источники · Редактор · Превью», панель публикации прилипает к низу экрана, источники показываются карточками.
