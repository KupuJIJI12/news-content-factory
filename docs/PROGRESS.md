# Статус проекта

Обновлено: 4 ноября 2026.

## Итог
Планы 1 и 2 выполнены и влиты в `main` (PR #1 и PR #2). Система работает локально: бэкенд через `dotnet`, админка через `npm`, PostgreSQL на машине владельца. Проверка Max вживую на тестовом канале и автонастройка Вестника Отрадного без VPN пройдены.

## План 1: конвейер (выполнен)
Документ: `docs/superpowers/plans/2026-10-23-backend-pipeline.md`
- Сбор новостей из RSS и HTML-источников, нормализация адресов, склейка дублей в сюжеты.
- Конвейер обработки: оценка интереса, рерайт, проверка фактов (детерминированная и через LLM).
- LLM: GigaChat и запасные провайдеры, очередь запросов, дневной бюджет токенов.
- Публикация в Max: разметка, дневной лимит, расписание, защита от повторной отправки.
- Hangfire, миграции EF Core, PostgreSQL.

## План 2: админ-API и веб-админка (выполнен)
Документы: `docs/superpowers/plans/2026-10-26-admin-api-and-spa.md`, доработки по приёмке `docs/superpowers/plans/2026-10-27-admin-feedback.md`
- REST API, вход по cookie, живые счётчики (SignalR).
- Админка «Контент завод» (React и Mantine, дизайн «Пульт выпускающего», всегда светлая тема, значок и манифест для телефона).
- Очередь сюжетов по вкладкам, карточка сюжета, правка черновика, перегенерация, публикация сразу или по расписанию.
- Города, источники, автонастройка источника (RSS, структура страницы, селекторы от LLM; заброшенные ленты пропускаются).
- Удаление пометкой: сюжет только из «Отклонено», источник целиком.
- Фото из статей источников и загрузка своих; по умолчанию пост уходит без фото.
- Рерайт: без названия города в заголовке, списки только к месту, ссылка на канал в конце поста.
- Устойчивый разбор ответов GigaChat.
- Проверка: 352 серверных теста, 73 теста админки, сборка без ошибок.

## Решения
- Развёртывание на VPS (план 3: Docker, nginx, бэкап-контейнер) не делаем: система работает локально на Windows.
- Ключи защиты данных отдельно не сохраняем: на Windows они хранятся в профиле пользователя.
- Фото источников автоматически не публикуются из-за авторских прав. Пост по умолчанию без фото, модератор добавляет фото сам. Фото источника можно взять только при включённом флаге «фото разрешены» у источника или с явным подтверждением.

## Отложено
- Поведение после сна или выключения ПК: нагон пропущенных задач без лавины публикаций.
- Мелочи: ответ 409 вместо 500 при гонках публикации и сохранения; сетевая ошибка выглядит как выход из системы; одно фото источника можно прикрепить дважды; предупреждение о лимите считается по сегодняшнему дню; восстановить удалённый сюжет нельзя; в настройках LLM можно указать любое имя переменной с ключом.
- Более понятное предупреждение о рисках при выборе фото источника.
- Стенд сравнения моделей и промптов `NewsFactory.EvalBench`, когда накопятся реальные новости.
- Законные источники картинок на будущее: свободные лицензии (Wikimedia), стоковые фото, иллюстрации ИИ, брендированная карточка.
